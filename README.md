# book-highlights

Play Books と Kindle で線を引いた箇所（ハイライト）を Obsidian に集め、AI で知識として整理するシステム。

## 課題

- Play Books の本と Kindle の本で線を引いた箇所がすばやく見られない
  - 現在: アプリを開く → 本を開く → ハイライトを見る
  - これをやめて、Obsidian に両アプリのハイライトを写す

## 目的

- 線を引いた箇所の文章という「点」が集まっていく
- それらを抽象化して、知識を「線」にし「面」にし「立体化」する

## 欲しい機能

- Play Books と Kindle のハイライトを管理・閲覧できる機能
- ローカル LLM がそれらの「点」を分析し、線 → 面 → 立体化する AI 分析機能
- AI がその知識からおすすめの本を紹介する機能

## 形態

- Web アプリ（モバイルファースト）
- ローカル LLM を動かすのは PC
- GitHub の静的サイトとして公開でよいが、AI 機能を使う場合の構成は未決定
